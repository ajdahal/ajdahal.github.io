Research

Machine learning testing, fairness, and realistic data generation.

My work studies how to test and analyze machine learning systems when data changes in realistic ways. I am especially interested in fairness testing, synthetic tabular data generation, and explainable AI methods that support more reliable model evaluation.

Fairness Testing

I study how combinatorial testing and latent-space representations can generate diverse test instances for identifying fairness issues in black-box machine learning models.

Project notes

Natural Changes in Tabular Data

This work focuses on generating counterfactual changes that are minimal, meaningful, and consistent with relationships among attributes in tabular datasets.
