# Adding Blog Posts

Create Markdown files in `_posts` using this filename format:

```text
YYYY-MM-DD-short-title.md
```

Use this front matter at the top:

```yaml
---
layout: post
title: "Your Post Title"
description: "One or two sentences describing the post."
---
```

Then write the post in Markdown below the front matter. After you commit and push, GitHub Pages will rebuild the site and list the post on `blogs.html`.
