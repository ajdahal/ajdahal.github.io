Past Projects

A key gap in fairness testing for machine learning is the rigorous generation of natural test cases. My research focuses on generating realistic, distribution-consistent test cases for evaluating fairness in machine learning models.

Much of my work studies how to test black-box models with inputs that remain meaningful in the data domain, rather than relying on synthetic perturbations that may violate feature relationships or produce invalid conclusions.

TabChange: Precise Attribute Changes in Tabular Data

Generate realistic counterfactuals for tabular data on sensitive attributes while preserving relationships among attributes. The counterfactual pair can be used for testing machine learning models for fairness, and satisfy counterfactual defination of individual fairness.

Fairness Testing of Machine Learning Models using Combinatorial Testing in Latent Space

Generate test instances in the latent space of a generative model using combinatorial testing to uncover discriminatory behavior in black-box machine learning systems. Leverage the relative independence of latent features and a decoder that knows the constraints of the dataset to obtain test cases with high naturalness in the input domain. Use combinatorial testing to efficiently search the latent space. This results in test cases for the causal definition of Individual Fairness Testing.

Dahal, Arjun, Sunny Shree, Yu Lei, Raghu N. Kacker, and D. Richard Kuhn. "Fairness Testing of Machine Learning Models using Combinatorial Testing in Latent Space." In 2025 IEEE International Conference on Software Testing, Verification and Validation Workshops (ICSTW), pp. 268-277. IEEE, 2025.
